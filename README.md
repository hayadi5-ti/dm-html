# Mini-site : Mes crêpes préférées
Devoir maison du module langages web côté client, par Houyem Ayadi (TI 105).
## Théme
Ce mini-site presente ma recette de crêpe préférée. Il explique les ingrédients, les étapes, les variantes et quelque astuces.
## pages
- index.html:page d'accueil qui présente la recette et le site
- pages/preparation.html : ingrédients, etapes numérotées et liens utiles.
- pages/astuces.html : variantes sucrées et salées, astuces et contact

## Ce que j'ai appris
